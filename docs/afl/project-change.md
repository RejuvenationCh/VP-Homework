# Why I changed the project

This project started as Media Cleaner during the weekly homework. The idea was to help users organize their media and clear storage. After reading the AFL1 brief again, I realized that storage cleanup did not fit the available tracks closely enough.

I decided to change it into a game backlog app. Track A includes organizing game collections, so this gives the project a clearer fit. Users will be able to organize games, track what they are playing or have finished, and keep ratings and notes. Steam import will bring in owned games, playtime, and achievements without having to enter everything manually.

I tested the Steam API in a separate test project before starting the change. It returned my owned games and playtime, along with PAYDAY 2's achievement list and my unlocked achievements. This confirmed that the data needed for those features is available for my account.

The earlier homework work is still useful. I plan to adapt the bubble layout, Material 3 theme, responsive layouts, and emulator testing tools for the game app. The bubbles will group games by genre instead of showing media storage. The updated screens will need another responsive check, and the H2 constraint examples will need to match the new content.

The Git history keeps the original Media Cleaner work so the weekly progress is still visible. This is a change in the app's purpose, with the existing UI work carried forward where it fits.
